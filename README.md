# tg-autopost

Автопостинг в Telegram-канал из папки `posts/`.

## Как добавить пост
1. Создай папку `posts/2026-10-12_1800_название/` (дата, время по UTC+7, название).
2. Положи `text.md` (подпись) и картинки `1.png`, `2.png` ... (до 10 - карусель). Можно `.mp4`.
3. Закоммить. Каждые 15 минут workflow публикует то, чьё время пришло, и ставит файл `.published`.

Подпись до 1024 символов уходит под фото, длиннее - отдельным сообщением после. Для HTML-разметки добавь `meta.json`: `{"parse_mode": "HTML"}`.
Посты старше 48 часов не публикуются. Запуск вручную: вкладка Actions, Run workflow.

Секреты: `TG_BOT_TOKEN`, `TG_CHAT_ID`.

## Гайды (PDF)
Положи в папку поста файл `*.pdf`: он уйдёт в Telegram отдельным документом после альбома. В Threads PDF не публикуется (там только картинки и текст).
