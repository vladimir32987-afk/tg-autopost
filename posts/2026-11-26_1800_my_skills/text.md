3 СКИЛЛА CLAUDE, КОТОРЫЕ ЭКОНОМЯТ МНЕ ЧАСЫ
Скилл - инструкция, которую пишешь один раз, а Claude берёт её сам.

1. Папка с файлом SKILL.md: внутри шаги, примеры и запреты
2. Описание в одну строку: по нему Claude понимает, когда скилл нужен
3. Работает сам: не надо каждый раз объяснять задачу заново

4. Рилсы по референсам: сначала найти залетевшие ролики, разобрать, потом собрать свой сценарий
5. Упаковка YouTube: тема, заголовок, описание и превью по аналитике конкурентов
6. Стиль текстов: короткие фразы, без штампов, только короткий дефис

Промпт для Claude или ChatGPT: «Я регулярно делаю задачу: [задача]. Вот как я её делаю: [шаги]. Вот пример хорошего результата: [пример]. Напиши SKILL.md: название латиницей, описание в одну строку (когда применять), шаги, частые ошибки. Коротко, без воды.»

В Инсте напиши СКИЛЛ в комментариях, пришлю в директ.
